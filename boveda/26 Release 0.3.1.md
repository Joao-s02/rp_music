# Release 0.3.1-alpha.1

Fecha: 2026-10-26. Estado: preparación autorizada, pendiente de confirmación de publicación.

El usuario terminó la prueba de 0.3.1 y autorizó publicarla y actualizar README. Confirmó buscador 10/10, resultados y audio rápidos, reproducción sin bugs ni lag observados. No indicó modelo/Android exacto/red/duración. Solo reporta errores de diseño sin detalle reproducible y pide aplazarlos a la próxima versión; no se atribuyen correcciones de diseño a esta release.

Comunicación solicitada: describir la capacidad de extensiones para conectar fuentes de música en la nube, por ejemplo catálogos como YT, evitando presentarla como conexión nativa general de la app. Se mantiene precisión: adaptador inicial Android, requiere paquete y permisos; no implica soporte de cualquier servicio ni red arbitraria dentro de programas. Detalles técnicos/proveedor permanecen en [[24 YouTube Music - definicion e investigacion]] y el contrato API 2.

Se publica el mismo APK validado: 0.3.1+10, 70362924 bytes, SHA-256 85c336c0d4b80cbfed111e4a128f2915927e95ae8674648e159d634657174b70. Se comprobó que el código/configuración y artefactos protegidos permanecen idénticos a los de la prueba. Solo documentación/publicación cambia en esta tarea; no se recompila ni se repiten pruebas de código sin cambios.

Ámbito: Android universal; Windows mantiene [[25 Release 0.3.0]]. Se conservan 77 pruebas automatizadas y pruebas nativas previas, distinguidas del reporte del usuario. Diseño, listas/favoritos/historial de la fuente, cuentas y Windows siguen pendientes. Se prepara fuente, tag y adjuntos verificados; publicación final se confirma abajo.
