# RP Music 0.3.10 — instalación y uso

Android: elegir APK universal o ARM64 compatible e instalar encima de la versión anterior, sin desinstalar. Conserva firma de desarrollo y datos. Windows: extraer TODO el ZIP en una carpeta nueva y ejecutar rp_music.exe junto a DLL/data; no copiar solo el ejecutable ni mezclar DLL anteriores. Conservar soporte privado de la app y su biblioteca.

Elegir carpeta musical y Actualizar biblioteca. La reproducción local no requiere cuenta ni red. Esta versión cambia el motor de Windows para mejorar M4A/OPUS; no modifica tus archivos. Android conserva su motor.

Extensiones → Explorar repositorio → https://github.com/Joao-s02/rp-music-extensions → Consultar. En Windows instalar YouTube Windows 0.4.1 o YouTube Explorador Windows 0.1.0, revisar permisos y elegir Usar esta fuente. Requieren app 0.3.10. Ambas usan API 2/Dart. Android conserva YouTube Android 0.4.0 y Explorador 0.1.0.

Explorador musical JS 0.1.0 funciona como pantalla independiente; no sustituye Fuente. Actualizar Radio por internet a 0.1.1 y abrir Radio JS: buscar o elegir emisora HTTPS MP3/AAC, escuchar y guardar favoritas privadas. Algunas emisoras/redes fallan o tardan más. No admite HLS. Las extensiones se instalan aparte; no están en APK/ZIP ni adjuntos de la app.

Letras incrustadas y LRC/TXT siguen disponibles; Letras locales puede buscar las ausentes con permiso. Consultas y audio remoto requieren red. No hay cuentas ni sincronización de YouTube. No se convierte YouTube a JavaScript.

Si falla audio, abrir diagnóstico y copiar el código de error sin compartir datos privados. Probar los mismos archivos y emisora usados antes. No se garantiza cualquier códec/archivo. Ver PRUEBAS-0.3.10.md y CAMBIOS-0.3.10.md. Las licencias de audio Windows están en licenses/windows_audio dentro del ZIP. SHA256SUMS.txt cubre los otros seis adjuntos.
