# RP Music 0.3.8-alpha.1 — JavaScript y Dart en paralelo

Añade API 3/JavaScript para extensiones que definen sus páginas, formularios, botones y acciones mediante componentes nativos combinables. **API 2/Dart se conserva: YouTube estable y Explorador no se modifican ni se convierten.**

**Laboratorio JS 0.1.0** demuestra tres páginas, saludo/formulario, contador persistente y búsqueda/reproducción local autorizada. Instalar desde https://github.com/Joao-s02/rp-music-extensions y pulsar Abrir pantalla. No sustituye Fuente ni viene dentro de los binarios.

**Descargas:**app 0.3.8+17, Android universal/global, ARM64 y Windows x64 portable completo, con USO/PRUEBAS/CAMBIOS y SHA256SUMS. Android se instala encima sin desinstalar; Windows requiere extraer todo el ZIP.

**Verificación:**122 pruebas aprobadas (120 de app +2 de extensión), una red optativa omitida, análisis limpio. Motor JS nativo Windows, interfaz a 360 px, estado/permisos y paquetes Dart reales comprobados. Falta prueba física Android.

Experimental: no es Node.js/npm ni HTML/CSS libre. API 3 todavía no ofrece red, cuentas, sincronización ni DSP; los límites no equivalen a aislamiento OS. YouTube Windows conserva límites conocidos. No se modifican releases anteriores.
