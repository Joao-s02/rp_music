# Cambios en RP Music 0.4.3

- La biblioteca muestra las acciones de canción en una tarjeta centrada. La cola usa un menú compacto junto a la canción. Ambos conservan sus acciones y su orden.
- Las fotos de artistas se controlan desde Ajustes → Apariencia.
- El fundido opcional se controla desde Ajustes → Reproducción. Está desactivado por defecto, con una duración inicial de 5 segundos y un rango de 1 a 12.
- El fundido solo se aplica al avanzar de forma natural. Si la siguiente pista cambia, es demasiado corta o no se prepara a tiempo, el avance puede continuar sin fundido.
