# RP Music 0.4.8

- En Android, la portada del álbum llega a 240 píxeles lógicos y se muestra sin la animación del disco.
- Los álbumes tienen una sola cabecera con Atrás y un menú para guardar en una lista o añadir a la cola.
- Los fondos de álbumes y listas muestran más detalle de la carátula.
- Windows comparte la barra superior de progreso de Android. Pulsa el minirreproductor para expandirlo y ajustar el volumen desde allí.
- Windows incorpora Esc, flechas para buscar en la pista, Ctrl con flechas para cambiar de canción, Espacio y Ctrl+F.

Incluye Android universal, Android ARM64 y Windows x64 portable.
