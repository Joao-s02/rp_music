# RP Music 0.5.0 Beta

El ecualizador del reproductor incorpora los modos Básico y Avanzado. Temas se abre desde Ajustes → Apariencia.

- Android incluye APK universal y ARM64. Si tu dispositivo admite ARM64, elige esa variante. Instala sobre tu versión actual para conservar los datos.
- Windows x64 incluye un ZIP portable. Extrae toda la carpeta y abre `rp_music.exe`.
- [Código fuente correspondiente de RP Music](https://github.com/Joao-s02/rp_music/releases/download/v0.5.0/RP-Music-0.5.0-source.zip)
- [Código fuente correspondiente de libmpv para Windows x64](https://github.com/Joao-s02/rp_music/releases/download/v0.5.0/libmpv-windows-20261110-1-sources.tar.xz)

Consulta los adjuntos de uso, cambios y pruebas para más detalles.

El SDK usado fue Flutter 3.47.6 con Dart 3.13.5. Revisiones exactas de [Flutter](https://github.com/flutter/flutter/tree/5fc346839b5d0eef006ed8404392afb4dfae428d) y del [motor](https://github.com/flutter/flutter/tree/692136cb6582dbfc5af3fb33c2515a069f2f66d0/engine/src/flutter).
