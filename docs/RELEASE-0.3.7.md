# RP Music 0.3.7-alpha.1 — YouTube Explorador independiente

Nueva navegación pública por artistas, álbumes y listas mediante **YouTube Explorador 0.1.0**, opción experimental con identidad propia. **YouTube Android 0.4.0 estable se conserva**: ambas pueden instalarse y se elige cuál controla Fuente.

Álbumes/listas cargados se importan como copias locales independientes que conservan orden, repeticiones y canciones al reiniciar. Importar no descarga audio ni modifica YouTube. Sin inicio de sesión ni sincronización de cuenta todavía.

**Extensiones:** instalar desde https://github.com/Joao-s02/rp-music-extensions . No vienen incluidas en APK/ZIP ni como adjuntos. Explorador reproduce en Android; YouTube Windows conserva sus límites conocidos.

**Descargas:** app 0.3.7+16, Android universal/global, ARM64 y Windows x64 portable completo. Android se instala encima sin desinstalar; Windows requiere extraer todo el ZIP. Guías USO/PRUEBAS/CAMBIOS y SHA256SUMS adjuntas.

**Verificación:** 114 pruebas aprobadas, análisis limpio de cambios, UI estrecha/importación/reinicio y navegación pública/paginación comprobados. Falta prueba física de Explorador. No se garantiza discografía exhaustiva ni todo contenido/región. Corrección M4A de 0.3.6 conservada.
