# Instalar y usar RP Music 0.3.16

Aplicación **0.3.16+25**. [Descargas oficiales](https://github.com/Joao-s02/rp_music/releases/tag/v0.3.16-alpha.1).

Android: abrir RP-Music-0.3.16-android.apk (universal) o RP-Music-0.3.16-android-arm64.apk (solo ARM64) desde Archivos y actualizar sin desinstalar. Universal para arm64-v8a/armeabi-v7a/x86_64. Conserva identidad de instalación y actualizaciones manuales. No se ha comprobado Play Protect ni instalación física de esta versión.

Windows: cerrar la versión anterior, incluida la bandeja. Extraer todo RP-Music-0.3.16-windows-x64.zip y abrir rp_music.exe dentro de RP-Music-0.3.16; conservar DLL/data/licencias juntos. Mantiene los datos del perfil de la app.

Las extensiones se actualizan por separado: abrir Explorar → Administrar extensiones → Explorar repositorio y actualizar desde el catálogo de https://github.com/Joao-s02/rp-music-extensions . YouTube Android/Windows0.5.3, YouTube Explorador Android/Windows0.2.3 y Explorador musical JS0.1.1 requieren app0.3.16. Android: youtube-music-android.rpmx y/o youtube-explorer.rpmx. Windows: youtube-music-windows.rpmx y/o youtube-explorer-windows.rpmx. Explorador JS: explorador-musical.rpmx. No es necesario instalar variantes de otra plataforma. El catálogo conserva también las variantes anteriores para clientes compatibles.

Explorar reúne fuentes y pantallas; Administrar extensiones conserva catálogo/permisos. Descarga de álbum: mantener la app abierta; progreso por canción y reintento de fallidas. Límite512MiB/canción en álbumes; las exportaciones individuales conservan64MiB. Necesita espacio para temporales; no reescribe música previa.

Prueba especialmente La Incondicional/Luis Miguel y Las Noches/Junior H como canciones sueltas, artistas con colaboradores/mayúsculas, lupa del álbum, indicador animado y fotos de artistas/portadas del Explorador. Los archivos descargados anteriormente no se reparan solos. Ningún servicio garantiza datos para toda canción.

Consultar PRUEBAS-0.3.16.md y CAMBIOS-0.3.16.md.
