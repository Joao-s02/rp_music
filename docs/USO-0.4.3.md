# Uso de RP Music 0.4.3

Mantén pulsada una canción en Android o haz clic derecho en Windows. En la biblioteca se abre una tarjeta centrada. En la cola aparece un menú al lado de la canción.

Para activar el fundido, abre Ajustes → Reproducción y selecciona la duración. El fundido suena cuando la cola avanza por sí sola. Al seleccionar otra canción o pulsar Siguiente, el cambio es inmediato.

Para mostrar u ocultar las fotos, abre Ajustes → Apariencia → Fotos de artistas.

Consulta la [guía general](https://github.com/Joao-s02/rp_music/blob/main/docs/USO.md).
