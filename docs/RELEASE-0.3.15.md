# RP Music 0.3.15-alpha.1 — instalación Android y Play Protect

Corrige el caso de advertencia de Play Protect probado con el usuario: Android ya no solicita permiso para instalar paquetes. Las futuras actualizaciones se descargan desde la página oficial y se abren desde Archivos. Música, letras sincronizadas, descargas y extensiones conservadas.

**Android: abrir el APK desde Archivos y actualizar sin desinstalar**, especialmente desde 0.3.13 por la transición de firma. Firma propia y conservación de identidad. Universal aceptado por Play Protect en emulador; el usuario confirma instalación directa sin alerta en su teléfono. No garantiza el resultado en todos los equipos; ARM64 no tiene análisis automático específico.

Android universal/ARM64 y Windows portable completo, USO/PRUEBAS/CAMBIOS/SHA256SUMS. Windows: cerrar la versión anterior y extraer todo el ZIP en carpeta nueva. Extensiones distribuidas por separado en el [catálogo](https://github.com/Joao-s02/rp-music-extensions); no necesitan una actualización de paquetes para este arreglo.

166 pruebas aprobadas, una optativa omitida y análisis limpio. Actualización del universal conserva lista de prueba y fecha original. Pendientes más dispositivos, ARM64 físico, escucha prolongada y latencia API 3 Android. No se desactiva Play Protect ni se envía apelación.
