# RP Music 0.2.6+8 — guía de uso

Android: instala el APK sobre 0.2.5 sin desinstalar para conservar los datos. Windows: cierra la anterior desde Salir en bandeja, extrae el ZIP completo y ejecuta rp_music.exe junto a sus DLL y data. Distribución preliminar: [v0.2.6-alpha.1](https://github.com/Joao-s02/rp_music/releases/tag/v0.2.6-alpha.1).

Elige una carpeta de música y usa Actualizar biblioteca para incorporar cambios. Escucha sin internet ni cuenta; buscar versiones es opcional y requiere conexión. Las novedades compartidas de Android/Windows son la ventana centrada de actualización, descarga en la app y orden por varios criterios con dirección persistida. Windows descarga ZIP pero no lo sustituye automáticamente.

En Android, Eliminar del dispositivo pide autorización de escritura de la misma carpeta si falta, además de la confirmación de borrado permanente. Cancelar conserva archivo y referencias. Ajustes → Permitir eliminar archivos permite autorizar antes. El proveedor del sistema puede negar escritura; no hay permiso general que puedas activar manualmente para SAF.

Para poner el reproductor en la pantalla de inicio, usa Ajustes → Pantalla de inicio → Añadir widget, o mantén pulsado el escritorio → Widgets → RP Music. Carátula/título abren la app; botones controlan la misma reproducción de la notificación. Colocar el widget no inicia música por sí solo.

Consulta PRUEBAS-0.2.6.md para comprobaciones detalladas y límites. Las extensiones programables con listas automáticas/carátulas están definidas como próximo trabajo; la extensión JSON disponible sigue siendo una prueba declarativa.
