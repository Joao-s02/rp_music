# Uso de RP Music 0.4.7

## Android

Instala el APK universal o el APK ARM64 si tu dispositivo es compatible. Para conservar los datos, instala encima de tu copia actual. Si Android solicita permiso para instalar desde el administrador de archivos, concédelo a esa aplicación para abrir el APK.

## Windows

Extrae todo el ZIP en una carpeta y abre `rp_music.exe`. Al actualizar, conserva tu carpeta de datos de usuario y extrae el paquete completo en una carpeta nueva.

## Biblioteca

Usa el selector superior para elegir Canciones, Álbumes, Artistas o Carpetas. Desde los tres puntos puedes actualizar la biblioteca y abrir Filtrado en las vistas que admiten un criterio de orden. En los detalles de listas y álbumes, Reproducir y Aleatorio inician la escucha de la colección.
