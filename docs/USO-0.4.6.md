# Uso de RP Music 0.4.6

**Android.** Usa ARM64 en el Redmi Note 10S. Instala sobre la versión anterior para conservar la biblioteca y las listas.

**Windows.** Extrae el ZIP completo y abre `rp_music.exe`. Conserva las DLL y la carpeta `data` junto al ejecutable.

Desliza arriba en el mini reproductor para expandirlo. En el reproductor expandido, el mismo gesto abre la cola. Para cerrarla, lleva el contenido al inicio y tira hacia abajo. Dentro de una lista, mantén pulsada una canción para quitarla y usa Deshacer si quieres recuperarla.
