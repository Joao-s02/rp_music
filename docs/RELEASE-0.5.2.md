# RP Music 0.5.2 Beta

En Android, abre **Reproductor → ⋮ → Compartir canción** para enviar el archivo de audio mediante una app compatible. Esta versión utiliza el ecualizador gráfico nativo de Android con la salida de audio estándar.

- Android incluye APK universal y ARM64. Instala sobre tu versión anterior para conservar la biblioteca y los ajustes.
- Windows x64 incluye un ZIP portable. Extrae la carpeta completa y abre `rp_music.exe`.
- [Código fuente de RP Music](https://github.com/Joao-s02/rp_music/releases/download/v0.5.2/RP-Music-0.5.2-source.zip)
- [Código fuente de libmpv para Windows](https://github.com/Joao-s02/rp_music/releases/download/v0.5.2/libmpv-windows-20261110-1-sources.tar.xz)

Compilado con [Flutter 3.47.6](https://github.com/flutter/flutter/tree/5fc346839b5d0eef006ed8404392afb4dfae428d) y Dart 3.13.5.
