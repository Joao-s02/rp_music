# Uso de RP Music 0.4.4

**Android.** Usa el APK universal o el ARM64 si tu dispositivo admite esa arquitectura. Abre el APK con Archivos e instala sobre la app existente para conservar los datos.

**Windows.** Extrae el ZIP completo en una carpeta y abre `rp_music.exe`. Mantén las DLL y la carpeta `data` junto al ejecutable.

En Biblioteca, toca el título para elegir Canciones, Álbumes, Artistas o Carpetas. Abre Ordenar para elegir criterio y dirección. Ajustes → Reproducción reúne el ecualizador, gapless, ReplayGain y fundido. Gapless viene activado y ReplayGain desactivado.
