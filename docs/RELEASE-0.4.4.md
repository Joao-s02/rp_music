# RP Music 0.4.4

Ecualizador con preajustes, reproducción sin pausas y ReplayGain opcional por canción o álbum. Los controles de vista y orden pasan a las cabeceras para dejar más espacio a la biblioteca.

Descargas para Android universal, Android ARM64 y Windows x64 portable. Los adjuntos incluyen instrucciones, cambios, pruebas y sumas SHA-256.
