# RP Music 0.3.5-alpha.1 — letras incrustadas y descargas etiquetadas

La base lee letras incrustadas. La extensión Letras locales busca automáticamente las que faltan y las guarda dentro de la app, sin modificar música local. YouTube Android mejora la búsqueda y prepara nuevas descargas M4A con metadatos, portada y letras disponibles, sin recodificar audio.

**Instaladores:** Android universal/global, Android ARM64 y Windows x64 portable completo. Instalar Android encima de la versión anterior sin desinstalar. Windows: extraer todo el ZIP. Aplicación 0.3.5+14; firma Android compatible con 0.3.4.

**Extensiones aparte:** https://github.com/Joao-s02/rp-music-extensions → consultar/actualizar y revisar permisos. YouTube Android 0.4.0 y Letras locales 0.1.0 requieren esta app. Biblioteca viva 0.1.1 y Pulso nocturno 0.1.0 continúan. Spotify se cancela y sale del catálogo; históricos preservados. No se adjuntan extensiones a esta release.

**Verificación:** 106 pruebas aprobadas, análisis limpio, prueba nativa Windows y prueba completa de metadatos sobre audio sintético aprobadas. Los tres casos del usuario recuperaron letras sincronizadas desde resultados reales YouTube. Detalles y pruebas pendientes en PRUEBAS-0.3.5.md.

**Límites:** sin retesteo físico Android de esta versión; selector SAF, archivos personales y escucha prolongada pendientes. Metadatos/letras dependen de cobertura y red. YouTube Windows mantiene fallos nativos conocidos y queda fuera del catálogo recomendado. Licencia del proyecto todavía sin elegir. Distribución oficial solo por GitHub, sin Play Store.

Adjuntos: dos APK, Windows ZIP, USO.md, PRUEBAS-0.3.5.md, CAMBIOS-0.3.5.md y SHA256SUMS.txt. Comparar hashes antes de instalar.
