# RP Music 0.3.20-alpha.1

Aplicación **0.3.20+29** para Android y Windows.

El minirreproductor queda por encima de los controles del teléfono. La navegación inferior se recoge al recorrer colecciones o extensiones y Atrás cierra el detalle o regresa a Explorar. El orden usa un menú compacto, Listas ofrece tarjetas cuadradas y Letras tiene una cabecera transparente que se recoge al desplazarse. La búsqueda de Biblioteca se despliega con una transición y muestra un solo conteo de pistas.

## Descargas

- `RP-Music-0.3.20-android.apk` para Android universal.
- `RP-Music-0.3.20-android-arm64.apk` para Android ARM64.
- `RP-Music-0.3.20-windows-x64.zip` para Windows x64 portable.
- `USO.md`, `PRUEBAS-0.3.20.md`, `CAMBIOS-0.3.20.md` y `SHA256SUMS.txt`.

En Android, abre el APK desde Archivos e instala sobre la versión anterior para conservar tus datos. En Windows, extrae el ZIP completo. Las extensiones se instalan desde su catálogo separado.
