# Uso de RP Music 0.4.5

**Android.** Instala el APK sobre la versión anterior para conservar los datos. En el Redmi Note 10S puedes usar ARM64.

**Windows.** Extrae el ZIP completo y abre `rp_music.exe` con las DLL y la carpeta `data` al lado.

El menú del reproductor reúne álbum, ecualizador, detalles y temporizador. Desliza arriba para la cola y abajo para volver. Mantén pulsada una lista en Android o haz clic derecho en Windows para ver sus acciones. La biblioteca comprueba cambios al iniciar desde cero.
