# RP Music 0.4.7

La cabecera de Biblioteca ahora muestra la sección activa con icono y reúne Filtrado y Actualizar en un menú. Listas y álbumes tienen nuevas cabeceras adaptables, carátulas difuminadas de fondo y opciones con el mismo estilo.

Incluye Android universal, Android ARM64 y Windows x64 portable. Consulta los adjuntos de cambios y pruebas, las instrucciones de uso y las sumas SHA-256.
