# RP Music 0.4.3

La biblioteca tiene una tarjeta de acciones centrada y la cola conserva un menú compacto junto a la canción. Abre las acciones con pulsación larga en Android o clic derecho en Windows. El interruptor de fotos de artistas está en Ajustes → Apariencia.

Puedes activar el fundido en Ajustes → Reproducción y elegir de 1 a 12 segundos para las transiciones naturales.

Descargas para Android universal, Android ARM64 y Windows x64 portable. Los documentos de uso, cambios, pruebas y hashes acompañan a los paquetes.
