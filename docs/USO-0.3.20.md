# Uso de RP Music 0.3.20

[Descargar RP Music 0.3.20-alpha.1](https://github.com/Joao-s02/rp_music/releases/tag/v0.3.20-alpha.1)

## Instalar y actualizar

**Android.** Descarga el APK universal o el ARM64 si tu teléfono admite esa arquitectura. Abre el APK desde Archivos e instala sobre la versión anterior para conservar los datos. El resultado de Play Protect depende del dispositivo.

**Windows.** Cierra RP Music, incluida la instancia de la bandeja, y extrae el ZIP completo. Abre `rp_music.exe` dentro de `RP-Music-0.3.20` y conserva al lado las DLL, licencias y la carpeta `data`. Los datos de usuario se mantienen en el perfil de Windows.

## Usar las novedades

- Desplázate hacia arriba para recuperar la navegación inferior después de recorrer una colección. Usa **Atrás** para cerrar el detalle o volver desde la extensión.
- Pulsa **Filtrar por** para elegir el criterio de orden y usa la flecha para cambiar la dirección.
- En **Ajustes → Apariencia → Vista de listas**, selecciona **Lista** o **Tarjetas**.
- Abre la lupa en Biblioteca para buscar. En **Letras**, desplázate hacia arriba para recuperar la cabecera.

Las extensiones se instalan por separado desde [rp-music-extensions](https://github.com/Joao-s02/rp-music-extensions). Consulta [las pruebas pendientes](PRUEBAS-0.3.20.md) y [los cambios](CAMBIOS-0.3.20.md).
