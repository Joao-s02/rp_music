# Cambios de RP Music 0.5.0 Beta

- El ecualizador se abre desde el menú del reproductor. El modo Básico incluye Plano, Graves, Voces y Agudos. El modo Avanzado permite editar cada banda y muestra las ganancias en una curva. Ambos modos comparten los ajustes guardados.
- Android usa las bandas disponibles en el dispositivo. Windows usa siete bandas con libmpv.
- Temas se abre desde Ajustes → Apariencia. Desde allí se puede consultar el catálogo y gestionar los temas instalados.
- Ajustes muestra «Beta» junto a la información de versión. El acceso a RP Edits desde Letras queda aplazado.
