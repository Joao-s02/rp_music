# RP Music 0.4.5

Menú del reproductor con ecualizador, temporizador y acceso al álbum. Gestos para la cola y los detalles, avisos breves de Deshacer, cabeceras móviles compactas, menús contextuales de listas y miniaturas persistentes. Mejora del control de salida en Android.

Incluye Android universal, Android ARM64 y Windows x64 portable. Los adjuntos incluyen instrucciones, pruebas, cambios y SHA-256.
