# RP Music 0.2.0-alpha.1 — primera base reconstruida

Versión preliminar del reproductor local para **Android** y **Windows x64**, reconstruida en Flutter. No requiere cuenta para utilizar tu música local.

## Descargas

- `RP-Music-0.2.0-alpha.1-android.apk`: aplicación Android, compilación release con firma de desarrollo para esta alfa.
- `RP-Music-0.2.0-alpha.1-windows-x64.zip`: aplicación portable completa. Extraer y ejecutar `rp_music.exe` sin separarlo de sus DLL y `data`.
- `USO.md`: instrucciones de instalación, reproducción, biblioteca y personalización.
- `descubrir.json`: ejemplo importable desde Extensiones.
- `SHA256SUMS.txt`: sumas de comprobación de los adjuntos.

## Incluido

Carpeta raíz con subcarpetas; vistas de canciones, álbumes, artistas y carpetas; búsqueda, favoritos y listas persistentes; reproducción básica, aleatorio, repetición de canción y consulta de cola. Interfaz adaptable en español, tema claro/oscuro y carátula de la pista activa.

La prueba de extensiones permite importar un manifiesto JSON, elegir la presentación de biblioteca y añadir la acción «Sorpréndeme» sin recompilar. Es declarativa: el runtime de código de terceros y las integraciones con servicios siguen pendientes.

## Validación

13 pruebas automatizadas aprobadas, análisis estático sin problemas y compilaciones release de Android y Windows. No se ha verificado reproducción física ni uso en una instalación limpia. La compatibilidad por códec, el servicio multimedia Android y el rendimiento requieren pruebas reales.

## Pendiente

Letras, edición de etiquetas, restauración de sesión, cola editable, bandeja y controles del sistema Windows, gapless y fundidos, SDK completo de extensiones, métricas de consumo y conexiones a servicios. Web queda fuera de esta entrega.
