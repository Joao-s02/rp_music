# RP Music 0.5.1 Beta

Diez bandas ajustables, filtros paramétricos y perfiles portables para el ecualizador. La cola permite mezclar sus pendientes y reiniciar la reproducción al completar una vuelta.

- **Android** ofrece APK universal y ARM64. Instala sobre tu versión actual para conservar los datos.
- **Windows x64** ofrece un ZIP portable. Extrae la carpeta completa y ejecuta `rp_music.exe`. El ecualizador de esta plataforma ofrece filtros gráficos y paramétricos con la DLL habitual.
- Consulta los adjuntos de uso, cambios y pruebas, así como el código fuente correspondiente de RP Music y libmpv.

SDK de compilación: [Flutter 3.47.6](https://github.com/flutter/flutter/tree/5fc346839b5d0eef006ed8404392afb4dfae428d), [motor Flutter](https://github.com/flutter/flutter/tree/692136cb6582dbfc5af3fb33c2515a069f2f66d0/engine/src/flutter) y Dart 3.13.5.
