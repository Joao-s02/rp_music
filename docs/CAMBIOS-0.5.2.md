# Cambios de RP Music 0.5.2 Beta

- Android permite compartir el archivo original de una canción local desde el menú del reproductor con el selector del sistema.
- Android usa la salida estándar de Media3 y recupera la ecualización gráfica con el efecto nativo. Los filtros paramétricos y los efectos adicionales siguen pendientes en Android.
- El reproductor conserva los perfiles de ecualización y las opciones para reiniciar, repetir y mezclar la cola.
