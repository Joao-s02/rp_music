# Uso de RP Music 0.3.18

Descargas: https://github.com/Joao-s02/rp_music/releases/tag/v0.3.18-alpha.1

## Instalar y actualizar

Android: abre RP-Music-0.3.18-android.apk (universal) o RP-Music-0.3.18-android-arm64.apk (solo ARM64) desde Archivos. Actualiza sobre la instalación anterior, sin desinstalar ni borrar datos. La app utiliza la misma identidad y linaje de firma. No se garantiza un veredicto de Play Protect. Las actualizaciones siguen la página oficial y Archivos.

Windows: cierra RP Music, incluida la bandeja, extrae todo RP-Music-0.3.18-windows-x64.zip y abre rp_music.exe dentro de RP-Music-0.3.18. Conserva DLL, data, fuentes y licencias. Los datos de la aplicación permanecen en el perfil del usuario.

## Biblioteca y búsqueda

Elige una carpeta raíz y espera el escaneo manual/progresivo. Las pistas aparecen por lotes; nombres y álbumes se completan después. Repetir el escaneo reutiliza etiquetas solo cuando las huellas del archivo siguen siendo válidas. Un fallo de lectura conserva la biblioteca anterior. No modifica las canciones. El botón Atrás dentro de un álbum vuelve al catálogo de álbumes.

Instala las extensiones por separado desde Explorar → Administrar extensiones → Explorar repositorio: https://github.com/Joao-s02/rp-music-extensions . Esta versión no requiere paquetes nuevos de YouTube. Conserva la variante de tu plataforma y los permisos que hayas aprobado.

Busca en la extensión, abre un artista/álbum, cambia a tu biblioteca local y vuelve a la misma extensión: conserva la pantalla reciente sin consultar de nuevo. Buscador y cabecera se desplazan con la lista. Atrás vuelve a la colección anterior. La caché vive solo en memoria: se pierde al cerrar la app, caduca y se invalida al modificar permisos o paquetes. No es historial sincronizado ni una sesión de YouTube.

Letras → Crear un edit descubre aplicaciones complementarias compatibles instaladas aparte. RP Edits Android no forma parte del APK ni del ZIP; Windows conserva la pantalla de disponibilidad sin editor/lanzador implementado.

## Conservación de biblioteca

Si los datos principales no son válidos, A01 intenta recuperar un respaldo completo y conserva el archivo rechazado como .rejected al guardar. Si ninguna copia sirve, bloquea el guardado para no sobrescribir los originales. No borres archivos privados para probarlo con datos reales ni desinstales la app para actualizar.

Consulta PRUEBAS-0.3.18.md y CAMBIOS-0.3.18.md para verificaciones y límites.
