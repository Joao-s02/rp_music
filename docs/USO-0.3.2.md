# Uso de RP Music 0.3.2

Android: instalar el APK universal o el ARM64 si el teléfono es compatible. Actualizar encima de la versión anterior para conservar datos. La firma actual es de desarrollo; no desinstalar si se desea conservar preferencias. Windows: extraer todo el ZIP y abrir rp_music.exe con sus DLL y carpeta data.

Elegir la carpeta de música y conceder lectura; el permiso de escritura se pide al eliminar. Biblioteca → Álbumes abre el detalle nuevo; Reproducir y Aleatorio crean la cola del álbum. Guardar como lista pide un nombre. Las opciones de eliminar siguen requiriendo confirmación.

Las extensiones se instalan por separado desde archivo o repositorio. Repositorio: https://github.com/Joao-s02/rp-music-extensions . Aceptar permisos solo de paquetes de confianza. Para la fuente inicial Android usar el paquete 0.2.0 compatible con 0.3.2; el paquete antiguo debe actualizarse. Su botón de navegación aparece al activar, autorizar y elegir la fuente. No se conecta a la red al usar únicamente música local.

La reproducción de fuentes sigue siendo experimental y depende del servicio; no se incluyen cuentas, favoritos, listas ni historial de fuentes en esta entrega. Windows conserva biblioteca y reproducción local. Descargas oficiales: https://github.com/Joao-s02/rp_music/releases/tag/v0.3.2-alpha.1 .
