# Instalar y usar RP Music 0.3.15

Aplicación 0.3.15+24. [Descargas oficiales](https://github.com/Joao-s02/rp_music/releases/tag/v0.3.15-alpha.1).

## Android

Descargar RP-Music-0.3.15-android.apk (universal) o android-arm64.apk para un dispositivo ARM64 compatible. Abrir desde Archivos/Descargas y actualizar sin desinstalar, para conservar listas, ajustes y extensiones. Desde 0.3.13, esta primera transición de firma se debe abrir desde Archivos; su antiguo instalador interno no reconoce la nueva firma. Android comprueba la transición de identidad.

La app consulta nuevas versiones y abre su página oficial. Descargar el siguiente APK en el navegador y abrirlo desde Archivos. Ya no solicita permiso para instalar paquetes. Mantener Play Protect activo. La prueba del usuario no mostró advertencia; si otro equipo la muestra, cancelar y registrar el mensaje exacto.

## Windows

Cerrar la versión anterior, incluida la bandeja. Extraer todo RP-Music-0.3.15-windows-x64.zip en una carpeta nueva. Ejecutar rp_music.exe junto a todas sus DLL, data y licencias. No reemplazar solo el ejecutable ni borrar la biblioteca o los datos de usuario. La lógica de actualización Windows no cambia.

## Música y extensiones

Elegir la carpeta musical y sus subcarpetas; no se modifica la música existente. Se conservan reproducción local, letras sincronizadas, descargas y extensiones. Los paquetes se instalan por separado desde el [catálogo de extensiones](https://github.com/Joao-s02/rp-music-extensions). Esta release no publica nuevos paquetes: conserva los disponibles para 0.3.13, incluidos YouTube 0.5.2 y Explorador 0.2.2. Revisar sus permisos. API 2 y API 3 siguen disponibles.

SHA256SUMS.txt permite comprobar los archivos descargados. No equivale a una certificación de seguridad.
