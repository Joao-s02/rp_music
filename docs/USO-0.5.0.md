# Uso de RP Music 0.5.0

## Android

Instala el APK universal o el APK ARM64 si tu dispositivo es compatible. Para conservar los datos, instala encima de tu copia actual. Si Android solicita permiso para instalar desde el administrador de archivos, concédelo a esa aplicación para abrir el APK.

## Windows

Extrae todo el ZIP en una carpeta y abre `rp_music.exe`. Al actualizar, conserva tu carpeta de datos de usuario y extrae el paquete completo en una carpeta nueva.

## Biblioteca

Usa el selector superior para elegir Canciones, Álbumes, Artistas o Carpetas. Desde los tres puntos puedes actualizar la biblioteca y abrir Filtrado en las vistas que admiten un criterio de orden. En los detalles de listas y álbumes, Reproducir y Aleatorio inician la escucha de la colección.

## Teclado en Windows

| Tecla | Acción |
| --- | --- |
| Esc | Cierra el reproductor o la búsqueda, o vuelve desde el detalle |
| Flechas izquierda y derecha | Retroceden o adelantan 5 segundos en el reproductor expandido |
| Ctrl + flechas izquierda y derecha | Cambian a la pista anterior o siguiente |
| Espacio | Reproduce o pausa con el foco en la pantalla principal o el reproductor |
| Ctrl + F | Abre la búsqueda |
| Tab y Mayús + Tab | Recorren los controles |

## Ecualizador y temas

Abre el menú del reproductor y elige Ecualizador. Puedes aplicar un preajuste en Básico o modificar la ganancia de cada banda en Avanzado. El interruptor activa o desactiva el efecto.

En Ajustes → Apariencia → Temas puedes elegir un tema, importar un archivo .rptheme o abrir el catálogo.
