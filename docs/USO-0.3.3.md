# Uso de RP Music 0.3.3

Android: instalar el APK universal o ARM64 compatible encima de la versión anterior. No desinstalar para conservar datos. Firma de distribución actual de desarrollo. Windows: extraer todo el ZIP y mantener ejecutable, DLL y data juntos.

Abrir el reproductor desde el control pequeño; deslizar verticalmente si el tamaño de pantalla/texto lo requiere. Detalles muestra datos reales y Cola permite cambiar pista. Anterior usa historial escuchado; Siguiente recupera avance al regresar y después sigue la política secuencial/aleatoria elegida.

En Álbumes, el botón de lista permite elegir una lista manual existente o crear una. Conserva canciones previas y evita duplicados. Artistas se agrupan por nombres separados con comas; no se reescriben los archivos.

Extensiones por separado, repositorio https://github.com/Joao-s02/rp-music-extensions . Consultar el catálogo desde Extensiones → Explorar repositorio, o importar desde previews/0.3.3: fuente 0.2.1 (nuevo icono) y Biblioteca viva 0.1.1 si se utilizan sus filtros de artistas. Revisar permisos antes de activar. La fuente inicial sigue siendo Android.

Ecualizador pendiente de una extensión futura. Descargas oficiales: https://github.com/Joao-s02/rp_music/releases/tag/v0.3.3-alpha.1 .
